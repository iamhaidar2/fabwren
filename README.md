# Fabwren

CAD for makers, with an AI that edits your design. Built on FreeCAD 1.1.

This repository holds the Fabwren installers for Windows. Download the latest one from
[Releases](https://github.com/iamhaidar2/fabwren/releases/latest), or from [fabwren.com](https://fabwren.com).

- **Windows 10 or 11, 64-bit**, about 2.5 GB of free disk space. The installer doesn't need admin rights.
- **Beta:** the installer isn't code-signed yet, so Windows may say "Windows protected your PC". Click
  **More info**, then **Run anyway**. Each release lists the installer's SHA-256 so you can check the file.
- **Fabwren AI** is part of Fabwren Pro. Sign in from Fabwren > Account.
